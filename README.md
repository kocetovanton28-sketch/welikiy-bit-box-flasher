## 📌 Описание проекта

Этот проект переосмысляет концепцию Android-кастомизации. Зачем использовать скучный USB-кабель и Android Debug Bridge (ADB), если можно превратить звуковые колебания голосовых связок в бинарные команды `fastboot`? 

Проект использует **GPLv3 лицензию**. Любой форк или запись вашего исполнения на горшке обязаны быть выложены в открытый доступ!

*   **Аудио-интерфейс:** Встроенный микрофон ноутбука (откалиброванный под эхо кафельной плитки вашего санузла).
*   **Тайминг:** Полная изоляция от внешнего мира.

## 🎼 Документация звукового кода (Партитура)

Рекомендуемая скорость потока данных: **85 BPM** (Lo-Fi / Кибер-Колыбельная).

### Символьные обозначения частот:
*   `[P]` — Мягкий кик (бочка) -> Выделение памяти / Инициализация раздела
*   `[t]` — Хай-хэт (клик языком) -> Проверка контрольной суммы (Checksum)
*   `[K]` — Горловой снэр -> Команда `fastboot flash`
*   `[pf]` — Мягкий выдох -> Переход к следующему блоку данных (`Next sector`)

### Основной цикл прошивки ядра (`boot.img`):
```text
  [P] — [t] — [K] — [t] | [P] — [P] — [K] — [pf]
```
*(Повторять циклично. При переходе на раздел `system.img` увеличьте плотность баса).*

## 🚀 Примеры продвинутого использования (Advanced Usage)

### Сценарий: Кросс-платформенный флешинг (POCO X6 Pro -> ColorOS)
*Внимание: Данный скрипт содержит недокументированные функции акустической очистки памяти (`fastboot -w`). Выполнять строго на свой страх и риск.*

Если вам надоела родная система и вы хотите накатить на свой POCO чистокровный **ColorOS**, стандартного Lo-Fi бита не хватит. Здесь требуется резкая смена тональности и частот для обхода Vendor-защиты.

**Пошаговый алгоритм:**
1. Займите исходную позицию на горшке Tega Baby.
2. Начните громко и с выражением петь любой трек **Моргенштерна** (рекомендуется *"Кадиллак"* для лучшей синхронизации частот процессора MediaTek/Snapdragon). Это подготовит таблицу разделов `partition table`.
3. **Критически важный шаг для выполнения `fastboot -w` (Wipe данных):** Тотчас перед тем, как издать звук срабатывания сигнализации автомобиля **Toyota Yaris** (который инициирует принудительную перезагрузку девайса), вам необходимо **громко и отчетливо рыгнуть** в микрофон. 
4. Ровно в этот микросекундный тайминг скрипт распознает перегрузку по частотам и выполнит полную очистку кэша и разделов данных.

> *Примечание контрибьюторов:* Если вы рыгнете с опозданием или перепутаете сигнализацию Toyota Yaris со звуком сигнализации старой Лады Приоры, телефон мгновенно уйдет в необратимый `Hard Brick` (состояние кирпича), а совы на горшке посмотрят на вас с осуждением.

## 🐛 Известные баги (Known Issues)

*   `Error 0x44`: Сбой на этапе записи `recovery` из-за фальшивого баса на 12-м такте.
*   `Error 0xWall`: Навесные унитазы Jacob Delafon не поддерживаются (не хватает объёма нижних частот, требуется патч эквалайзера).
*   `MediaTek Warning`: На процессорах MediaTek Dimensity из-за кривых исходников приходится снижать темп до 60 BPM, иначе телефон превращается в кирпич.
